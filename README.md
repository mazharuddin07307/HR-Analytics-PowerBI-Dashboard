# HR Analytics Dashboard – Power BI

## 📊 Project Overview
This project is an interactive **HR Analytics Dashboard** built using **Microsoft Power BI**. It provides a comprehensive view of workforce data, helping HR teams and management make data-driven decisions related to employee attrition, compensation, and workforce demographics.

## 🎯 Key Insights Covered
- **Employee Attrition** – Attrition rate, trends, and key factors driving employee turnover
- **Compensation Analysis** – Salary distribution across departments, roles, and experience levels
- **Workforce Demographics** – Breakdown by age, gender, department, and tenure
- **Department-wise Performance** – Headcount and metrics across different departments

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard design and data visualization
- **Microsoft Excel** – Data cleaning and preparation
